Transportation Management System — Java

An academic group project focused on designing and developing a transportation management system using Java.

The system was designed to manage riders, drivers, and vehicles, while organizing and maintaining records through custom data structures.

Key Concepts & Implementation:

* Object-Oriented Programming (OOP).
* Classes, Interfaces, and Enumerations.
* Custom Linked List Implementation.
* Data Validation and Input Constraints.
* Sorting and Searching Operations.
* Date and Time Comparison.

Technologies: Java

Project Type: Academic Group Project
